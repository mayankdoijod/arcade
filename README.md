# Python Arcade 🎮

A collection of four classic games built using Python, presented through a custom-designed web interface.

## 🎯 Games Included

- **Higher or Lower** — Guess the secret number with limited attempts.
- **Blackjack** — Play the classic card game against the computer.
- **Hangman** — Guess the hidden word before running out of lives.
- **Stone Paper Scissors** — Challenge the computer in this classic game.

## 🛠️ Technologies Used

- Python
- HTML
- CSS
- JavaScript
- Pyodide for running Python in the browser

## 📁 Project Structure

- `frontend/` — Website interface and styling.
- `games/` — Separate Python files for each game.
- `README.md` — Project documentation.

## 🚀 Running the Project

Open `frontend/index.html` using a local web server to run the website.

Some features require an internet connection to load Pyodide.

## 📌 About

Python Arcade is a college mini project created to explore Python programming through familiar games and a custom web interface.
