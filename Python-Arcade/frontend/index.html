PROJECT CURATION // 2026

A SMALL PROJECT.
A BIGGER REASON.

Python Arcade is a college mini project exploring Python through four familiar games. Each game has its own implementation, brought together under one visual identity.

In an era dominated by sprawling enterprise systems and automated template generation, there remains profound beauty in fundamental computer science. This collection celebrates the core principles of algorithmic problem-solving: game loops, state evaluation, randomness, condition branching, and textual interaction.

[ 01 ]

Modular Architecture

Each title exists in its own isolated Python directory, maintaining clean separation of concerns.

[ 02 ]

Zero Bloat

Engineered using standard Python libraries. No external frameworks, heavy dependencies, or bloatware.
